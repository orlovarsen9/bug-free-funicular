## v83 — смена паролей через Google Таблицу

В листе «Пользователи» добавлены две колонки:
- «Новый пароль»
- «Статус пароля»

Как менять пароль:
1. Найдите нужного пользователя.
2. В колонке «Новый пароль» введите новый пароль (минимум 6 символов).
3. Apps Script применит его к этому аккаунту.
4. После применения поле с чистым паролем автоматически очищается.
5. В «Статус пароля» появится отметка о смене.

Работает для:
- Административных правок;
- Наблюдателя;
- всех Менеджеров;
- всех учебных аккаунтов.

ВАЖНО:
текущие пароли специально не выводятся в таблицу — в базе они хранятся как хэши.
Для этой функции обязательно заменить google_apps_script_backend.gs и выпустить New version Apps Script.

## v85 — права наблюдателя на проекты

1. Наблюдатель может полностью удалить проект из корзины.
   - В корзине появилась кнопка «Удалить полностью».
   - После подтверждения проект физически удаляется из общей базы.
   - Восстановить его после этого нельзя.

2. Наблюдатель может менять номер любого проекта.
   - В карточке проекта появилась кнопка «Изменить номер».
   - Можно указать 2, 5, 25 и т.д.
   - На экране номер форматируется как №002, №005, №025.
   - Если такой номер уже занят другим проектом, система не даст создать дубль.
   - Изменение номера записывается в полную историю проекта.

ВАЖНО:
для этих функций обязательно заменить google_apps_script_backend.gs
и сделать Deploy → Manage deployments → Edit → New version → Deploy.
